# Simple Linear Regression - Real Estate Price Prediction

This project demonstrates the implementation of **Simple Linear Regression** to analyze the relationship between property size and real estate price.

## Project Overview

The objective of this project is to analyze the relationship between property size and real estate price using Python.

The analysis includes:

- Loading the dataset
- Exploring the dataset
- Descriptive statistical analysis
- Visualizing the relationship between property size and price
- Simple Linear Regression analysis

## Dataset

The dataset contains two variables:

| Variable | Description |
|----------|-------------|
| `price` | Real estate property price |
| `size` | Property size |

The dataset contains **100 observations**.

## Technologies & Libraries

- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Statsmodels
- Seaborn

## Analysis

The project explores the relationship between:

- **Independent variable:** `size`
- **Dependent variable:** `price`

A scatter plot is used to visualize the relationship between property size and price.

## How to Run
1. Download or clone this repository.
2. Open SimpleLinearRegression.ipynb using Google Colab or Jupyter Notebook.
3. Make sure real_estate_price_size.csv is available in the same directory.
4. Run the notebook cells sequentially.

## Result
The analysis shows a positive relationship between property size and real estate price. The project demonstrates how Simple Linear Regression can be used to analyze this relationship.
